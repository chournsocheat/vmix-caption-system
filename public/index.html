Google Cloud mode switches from the browser's Web Speech API to server-side streaming recognition, which can auto-detect mixed languages (e.g. Khmer + English) in one stream. Overlay 1 always updates automatically once each sentence completes (~1s after you pause) — "Live Overlay 1" additionally pushes it continuously word-by-word while you're still speaking. Overlay 2 always waits for the complete sentence, since translating a half-formed phrase isn't meaningful.

🎚️ To caption vMix's own program audio (not just a mic), route vMix's audio output (Settings → Audio, or an Input's Bus A/B) to VB-Audio Virtual Cable, then select "CABLE Output (VB-Audio Virtual Cable)" above.
